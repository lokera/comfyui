# Wan 2.2 I2V workflow

The installer downloads the current official ComfyUI template at runtime and creates:

`/content/ComfyUI/user/default/workflows/Wan2.2_I2V_T4_Social.json`

T4 first-pass settings:

- 320 × 576
- 49 frames
- 24 FPS
- about 2.0 seconds

The workflow is Image → Video, designed as a starting point for vertical social media content.
